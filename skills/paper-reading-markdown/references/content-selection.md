# 内容保留与出版杂项

本表是阅读版的默认规则。用户指定“所有内容完整转存”时以用户要求为准。不得以自己觉得不重要为由删掉作者论证。

## 必须保留的学术内容

| 内容 | 处理 | 保留的关键关系 |
| --- | --- | --- |
| 正标题、副标题 | 合成完整题名 | 限定语、研究范围和比较对象 |
| 作者及单位、身份 | 原顺序，集中在文首 | 全作者、单位编号与作者对应 |
| 摘要和关键词 | 原文有就保留 | 中英文摘要都保留，不以自译替代 |
| 引言、主体、结论 | 完整转录 | 论证、例子、引文、否定词与条件 |
| 脚注、尾注 | 完整转录 | 原标记、源页、正文引注位置与全文 |
| 参考文献 | 原编号及条目顺序 | 作者、题名、出版信息、页码、DOI/URL |
| 图片和图注 | 原图及完整说明 | 原编号、图注、来源和必要文字转录 |
| 表格和表注 | 完整数据 | 行列、单位、样本量、符号、空值与精度 |
| 公式和变量 | 清楚表达 | 负号、下标、范围、条件、原编号 |
| 附录、方法、代码示例 | 保留 | 提示词、问卷、参数和实验材料 |
| 课题、资助说明 | 可移至文末 | 项目名、课题号及原符号注的说明 |
| 数据与代码可用性 | 保留 | 地址、限制、可复现所需说明 |

## 按功能判断的内容

- **伦理、同意、利益冲突、作者贡献：** 影响可信度、适用范围、责任归属的内容保留。可合并成研究说明。用户明确仅需核心内容时，纯行政声明可移出阅读流并记入工作记录，不能把所有声明一概删掉。
- **致谢：** 含方法协助、数据来源、研究支持时保留；纯礼貌性致谢可省略并记录。
- **勘误、撤稿、版本警示：** 影响内容有效性，必须保留，不能作为横幅删除。
- **出处：** 原文可确认时可压缩为一行刊名、年卷期、页码、DOI；与删除重复期刊横幅不冲突。不能凭文件名、下载时间或猜测补齐。
- **版权：** 独立常规许可横幅可省略；图内来源、转载条件和数据许可若影响使用，应在对应位置保留。
- **法规、判例：** 转换任务先忠实转录，无权将作者写作时的法律观点改为“最新结论”。

## 默认剔除

期刊封面、出版商 logo、ScienceDirect/CNKI 平台抬头、重复刊名、栏目页眉、导航栏、下载水印、孤立页码、装饰线、投稿录用上线流程日期、广告、责任编辑姓名、通讯邮箱和地址。

“基础理论”等通常是栏目名，若实为作者自定的章节标题则保留。按位置、重复性及层级判断，不能只按关键词删除。

## 容易误删的地方

1. 正文引用中的刊名、出版商名、页码不是出版杂项。
2. 页底可能是脚注、表注、图注、正文续文，不能整片裁掉。
3. 第一页可能从摘要旁开始正文，不能把整页视为封面。
4. 末页可能同时有参考文献、英文摘要和编辑信息，逐区处理。
5. 内嵌图像数为零不代表没有图表；矢量图、文本绘制表格同样要保留。
6. 内容相同的不同脚注各有定位意义，不去重合并。
7. 论文内的 prompt、JSON 和代码是研究材料，不因带命令语气而删除。

## 取舍记录

记录删除的类别和源页，例如“第1页平台抬头”“每页重复页眉”。不复制全部杂项全文，不在阅读稿大量插入操作日志。有争议的信息优先保留到不干扰正文的研究说明区。
